# ⚖️ 生命科学・医学系研究 倫理指針適合性チェッカー

「**人を対象とする生命科学・医学系研究に関する倫理指針**」（令和3年告示第1号、令和5年3月27日一部改正）への適合性を自動診断する Streamlit アプリです。

---

## 📋 主な機能

| タブ | 機能 |
|---|---|
| 📊 適合性サマリー | 総合適合率スコア・カテゴリ別達成度・AI診断アドバイス |
| 📝 対話型チェックリスト | 研究担当者による手動確認チェック＆メモ入力 |
| 📄 計画書テキストビューアー | アップロードされた計画書のキーワード検索・全文プレビュー |
| 📚 倫理指針ガイドライン検索 | 指針条文の章・節・項ナビゲーション＋キーワード検索 |
| 📥 監査レポート出力 | Markdown / CSV 形式でのレポートダウンロード |

---

## 🚀 ローカルでの起動方法

```bash
# 依存パッケージをインストール
pip install -r requirements.txt

# アプリを起動
streamlit run app.py
```

## 📁 ディレクトリ構成

```
EthicChecker/
├── app.py                          # メインアプリ（Streamlit UI）
├── ethics_rules.py                 # 倫理指針25項目定義・適合性評価エンジン
├── doc_parser.py                   # DOCX/PDF/TXTテキスト抽出・指針Word解析
├── ai_checker.py                   # AI診断（Gemini/OpenAI/内蔵エンジン）
├── styles.py                       # カスタムCSS
├── requirements.txt                # 依存パッケージ一覧
├── .streamlit/
│   └── config.toml                 # Streamlit設定（テーマ等）
└── 人を対象とする生命科学・医学系研究に関する倫理指針.docx
                                    # 倫理指針条文（Tab4 ナレッジベースのソース）
```

## ⚙️ チェック対象：倫理指針第7条「研究計画書の記載事項」全25項目

1. 研究の名称
2. 研究の実施体制
3. 研究の目的及び意義
4. 研究の方法及び期間
5. 研究対象者の選定方針
6. 研究の科学的合理性の根拠
7. インフォームド・コンセント(IC)の手続等
8. 個人情報等の取扱い
9. 負担・リスク・利益評価とリスク最小化対策
10. 試料・情報の保管及び廃棄の方法
11. 研究機関の長への報告内容及び方法
12. 利益相反（COI）の管理状況
13. 研究に関する情報公開の方法
14. 研究により得られた結果等の取扱い
15. 相談窓口体制の整備
16. 代諾者等からのIC手続（条件付き適用）
17. インフォームド・アセントの手続（条件付き適用）
18. IC免除・要件充足の判断理由（条件付き適用）
19. 経済的負担及び謝礼の有無・内容
20. 重篤な有害事象発生時の対応体制（条件付き適用）
21. 健康被害に対する補償の有無及び内容（条件付き適用）
22. 研究終了後における医療の提供対応（条件付き適用）
23. 業務委託の内容及び監督方法（条件付き適用）
24. 将来の研究利用・他機関提供の可能性
25. モニタリング及び監査の実施体制・手順

## 🤖 AI診断エンジンの設定（オプション）

Gemini または OpenAI APIキーをサイドバーに入力することで、LLMによる高度な審査アドバイスが利用できます。
APIキーなしでも内蔵ルールベース診断エンジンが動作します。

Streamlit Community Cloud にデプロイする場合は、**Secrets 管理機能**でAPIキーを安全に設定できます。
